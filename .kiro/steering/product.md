# ForgeLoop Product Steering

ForgeLoop is an open source operating system for AI-assisted engineering.

It helps builders move quickly without losing clarity, memory, review quality, or learning.

The product promise is:

- inspect before changing
- plan before building
- build in small steps
- review from multiple viewpoints
- capture reusable lessons

The core loop is Discover, Frame, Build, Check, Capture.

Keep the beginner experience simple. Prefer clear commands and short files over hidden automation.
