# Code Of Conduct

ForgeLoop is built for people who want AI-assisted engineering to be clearer, safer, and more humane.

## Expected Behaviour

- Be respectful and practical.
- Assume good intent, but accept correction.
- Keep feedback focused on the work.
- Explain risks plainly.
- Make space for beginners.

## Unacceptable Behaviour

- Harassment, insults, or personal attacks.
- Publishing private information.
- Sharing secrets, tokens, or exploit details in public issues.
- Dismissing safety concerns without evidence.
- Using ForgeLoop community spaces for spam.

## Reporting

When the repository is public, report conduct issues through the maintainer contact listed in the GitHub repository.

Security vulnerabilities should follow `SECURITY.md`.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or participants that harm the project.
