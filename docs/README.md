# Docs

This folder stores the working memory of ForgeLoop.

Each stage has its own folder so tasks leave a clear trail:

- `discoveries/`: what was inspected before planning
- `frames/`: scoped plans
- `builds/`: implementation notes
- `checks/`: validation and reviewer findings
- `captures/`: lessons, decisions, and changed facts
- `solutions/`: reusable answers to problems
- `standards/`: rules and policies
- `language/`: shared project terms
- `decisions/`: durable trade-offs
- `benchmarks/`: measured evidence for public claims
- `compatibility/`: tool support, deployment matrix, and acceptance prompts
- `integrations/`: optional peer integrations such as OpenCLI
- `palace/`: domain-shaped long-term memory

If a note might help a future task, store it here instead of leaving it only in chat.
