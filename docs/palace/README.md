# Palace

The palace folder stores long-term memory in a spatial structure.

Use:

- `wings/` for broad domains
- `rooms/` for focused workstreams or sessions
- `drawers/` for exact memory artefacts
- `entities/` for named things that change over time
- `timelines/` for time-aware facts
- `indexes/` for findability

The palace should make memory easy to retrieve, not harder to maintain.
