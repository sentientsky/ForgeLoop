# Check: Release Readiness Audit

## Scope

Reviewed ForgeLoop's release path, Python CLI behaviour, memory index, compatibility profiles, external-secrets workflow, GitHub workflow safeguards, package build, and optional OpenCLI integration.

## Verified Locally

- `python -m ruff check --no-cache forgeloop tests`
- `python -m unittest discover -s tests`
- `python -m coverage run -m unittest discover -s tests`
- `python -m coverage report`
- `python -m forgeloop validate .`
- `python -m forgeloop doctor .`
- `python -m forgeloop compat .`
- `python -m forgeloop index . --check`
- `python -m forgeloop secrets check .`
- `python -m forgeloop pack "release readiness security memory compatibility" . --limit 5`
- `python -m forgeloop tokens "release readiness security memory compatibility" . --tool all-supported --limit 5`
- `python -m build`
- `python -m twine check dist/*`
- `python tests/package_smoke.py dist .`

## Findings

### Resolved

- External secrets creation now rejects dangling symlinks, rechecks the parent directory after creation, and uses `O_NOFOLLOW` where the operating system supports it.
- External secrets health checks now reject non-file paths instead of treating a directory as a valid secrets file.
- OpenCLI plugin installation now rejects symlinked plugin sources and manifests, stops after a failed critical step, and verifies `opencli list -f json` as promised by the install plan.
- The development dependency floor now requires Twine 7 because older local Twine releases reject the valid Core Metadata 2.5 generated by current Hatchling.

### External Limitation

An isolated attempt to fetch the optional OpenCLI peer package with npm lifecycle scripts disabled exceeded the two-minute test bound. No global OpenCLI installation, daemon, browser bridge, or credential access occurred. The repository's plugin source, manifest, dry-run plan, and mocked execution path are covered locally. Refresh the live peer-package check when a reliable network connection is available.

## Result

No release-blocking local defect remains. Public release still requires the owner-only GitHub and PyPI configuration listed in `docs/GITHUB_SETUP.md` and `docs/ROADMAP.md`.
