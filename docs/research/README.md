# Research Notes

Research notes are timestamped working records. They are useful for product history, but they may describe gaps that were later fixed.

Before treating an older research note as the current project status, check:

- `docs/ROADMAP.md`
- `docs/RELEASE_GUIDE.md`
- `docs/GITHUB_SETUP.md`
- `docs/palace/indexes/memory-index.md`

Do not rewrite old research to pretend the project always had the current answer. Prefer adding a newer capture, decision, benchmark, or roadmap update.
