# What ForgeLoop Is

ForgeLoop is an open source operating system for AI-assisted engineering.

It helps a person work with AI coding tools without losing clarity, memory, review quality, or control.

## The Simple Version

ForgeLoop gives your AI coding assistant a repeatable team-like workflow:

1. Discover what is true.
2. Frame the work.
3. Build in small steps.
4. Check the result.
5. Capture the lesson.

The system is mostly markdown, templates, reviewer roles, lightweight Python validation, and optional integrations.

## What Problem It Solves

AI coding tools are fast, but they can:

- forget decisions
- reload too much context
- skip planning
- skip review
- repeat mistakes
- store secrets by accident
- make confident claims without evidence

ForgeLoop makes those failure modes visible and harder to repeat.

## What Makes It Different

ForgeLoop is not a giant prompt.

It is a small operating system with:

- short always-loaded instructions
- on-demand skills
- specialist reviewers
- measured context packets
- local-first memory
- release health checks
- explicit optional integrations

## The Memory Model

ForgeLoop stores useful knowledge in normal markdown.

The memory palace is organised into:

- captures for lessons and changed facts
- solutions for reusable patterns
- decisions for durable trade-offs
- language for shared terms
- indexes for quick lookup

The full content stays readable by humans. Context packets only point to likely files, so agents do not need to load every note.

## Who It Is For

ForgeLoop is for:

- solo builders
- vibe coders who want more discipline
- non-programmers guiding AI coding tools
- open source maintainers
- teams experimenting with AI-assisted development

## What It Is Not

ForgeLoop is not:

- a hosted service
- a replacement for tests
- a secret store
- an automatic browser agent
- a promise of fixed token savings
- a copy of another memory system

## Public Release Position

The public MVP is local-first and dependency-light.

Optional integrations such as OpenCLI are integrated as peer tools and require explicit user action before install.
