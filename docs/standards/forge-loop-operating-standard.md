# ForgeLoop Operating Standard

ForgeLoop should feel like a product, not a loose prompt pack.

## Standard Workflow

Use the five-stage loop:

1. Discover
2. Frame
3. Build
4. Check
5. Capture

## Standard Review Priorities

- P1: must fix before completion.
- P2: should fix soon.
- P3: useful improvement, not blocking.

## Standard Writing Style

- Use UK English.
- Keep instructions simple.
- Prefer practical examples.
- Avoid hype.
- Avoid unexplained jargon.

## Standard Memory Behaviour

- Preserve exact wording when it matters.
- Summarise only after preserving the important source.
- Mark old facts as superseded instead of deleting them.
- Link related notes.
- Never store secrets.

## Standard Product Shape

The workflow should stay simple at the surface.

The memory palace should be a deeper support layer, not a second competing product.
