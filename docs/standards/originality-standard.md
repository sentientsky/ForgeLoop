# Originality Standard

ForgeLoop is open source, but it must still be original.

## Rules

- Do not copy another project's code.
- Do not copy another project's prompts, agent text, docs, branding, or claims.
- Do not use another project's unusual product terms unless they are generic and necessary.
- Do not rely on celebrity, hype, star counts, or benchmark theatre for credibility.
- Explain what ForgeLoop actually does in plain language.
- Credit research inspiration when useful, but make the implementation our own.

## Product Language

Use ForgeLoop's own language:

- Discover
- Frame
- Build
- Check
- Capture
- memory records
- capture notes
- solution notes
- entity notes
- timeline notes
- local memory index

## Claims

Any performance or benchmark claim must include:

- exact dataset
- exact command
- exact environment
- result file
- limitations
- whether an LLM was used

If we cannot reproduce it, we do not claim it.
