# TDD Tracer Bullet Standard

Use TDD when a small behaviour slice can reduce implementation risk.

## Rules

- One behaviour slice at a time.
- Test through public surfaces where possible.
- Avoid implementation-detail tests.
- Refactor after green checks.
- State what is intentionally untested.
