# Memory Refresh Standard

ForgeLoop memory should stay useful without rewriting history.

## Classifications

- Keep: still useful as written.
- Update: needs a small current note.
- Consolidate: duplicates another note.
- Supersede: old guidance remains historical but should not guide new work.
- Stale: likely outdated, needs review before use.
- Delete candidate: safe to remove only after human review.

## Rules

- Never delete automatically.
- Prefer superseding to rewriting old facts.
- Refresh indexes after memory changes.
- Do not store secrets or private data.
