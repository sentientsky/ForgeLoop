# Benchmarks

Benchmarks record measured evidence for public claims.

ForgeLoop does not make fixed 80 percent or 90 percent token-saving claims by default.

Use:

```bash
python -m forgeloop tokens "<query>" . --tool <tool> --limit 5
```

Each benchmark should include:

- date
- command
- tool profile
- exact flag
- packet tokens
- selected source tokens
- corpus source tokens
- savings percentage
- caveats
