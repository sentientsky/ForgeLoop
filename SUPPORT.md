## Before Asking For Help

Run:

```bash
python -m forgeloop doctor .
python -m forgeloop validate .
```

Include the output in your issue if it is safe to share.

Do not include secrets, tokens, private repository data, browser cookies, or private account content.

## Security Issues

Use `SECURITY.md`.

Do not publish exploit details in public issues.
